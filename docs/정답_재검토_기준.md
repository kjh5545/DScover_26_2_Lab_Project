# 상세 환자 정답 재검토 기준과 변경 기록

## 배경
- 11/04 새 상세 환자 4명 독립 검증 뒤, 인선이 "정답 쪽 문제일 수 있는" 기준 4건을 확인 요청했어요(`docs/판정프롬프트비교_결과.md`의 "팀에 확인할 것").
- 이 재검토는 **AI 결과를 본 뒤**에 하는 거예요. 그래서 아래 순서를 지켜요.
  1. 규칙 문장을 먼저 확정해요(팀 동의).
  2. 상세 환자 6명(S004, S008, S002, S010, N001, N002) 시트 전체에서 해당하는 칸을 **모두** 같은 규칙으로 고쳐요. AI가 틀린 칸만 고치지 않아요.
  3. 고칠 때 AI 판정은 보지 않아요.
  4. 변경 기록을 남기고, 다른 한 명이 기록을 확인해요.
  5. 점수는 **고치기 전 정답(v1)과 고친 뒤 정답(v2) 둘 다** 보고해요.

## 확정된 규칙 (11/06 팀 단체 채팅방 동의)
> **기준 A:** 명시된 사실과 정의상 함께 있을 수 없는 경우만 통과로 본다. (예: 남성·폐경 → 임신·수유 아님, 나이 → 소아 아님)
> **예외:** 진단명 하나로 다른 진단이나 원인을 배제하는 경우(예: 제2형 진단 → 제1형 아님)는 진단이 바뀔 수 있으므로 모름으로 본다.

- 제1형과 제2형은 분류상 한 사람에게 하나만 붙지만, 성인 잠복 자가면역 당뇨(LADA)처럼 처음에 제2형으로 진단했다가 나중에 바뀌는 경우가 있어요. 그래서 예외로 둬요.

### 어떻게 읽어야 하나
- **정답 버전에 따라 바뀌지 않는 결론 (믿을 만함)**
  - 팀 결정이 들어간 p2 이후 조건이 규칙 없음(p0), 사전 실험 규칙(p1), AI가 쓴 규칙(control)보다 확실히 높아요. 차이는 v1 기준 약 4~7개, v2 기준 약 8~14개예요.
  - 등록 후 확인 구분은 p2 이후 20/26, p0·p1·control은 14/26 안팎이에요. 버전과 상관없이 같아요.
  - 규칙을 더할수록 통과·탈락 정답은 줄어요. v1은 73 → 62, v2는 68 → 63이에요. AI가 더 조심스러워진다는 발견은 그대로예요.
- **정답 버전에 따라 뒤집히는 결론 (말하면 안 됨)**
  - p2, v3, v3_r1112 사이의 순서예요. v1에서는 p2가 1등이고 v2에서는 v3_r1112가 1등이에요. 차이도 1~3개뿐이에요.
  - 특히 기준 B는 규칙 11과 내용이 같아서, v2에서 v3_r1112가 오른 건 **정답을 규칙 11에 맞춘 효과**가 섞여 있어요.
- 결론: **"팀 결정(수동 스크리닝)이 효과가 있다"는 두 버전 모두에서 성립해요. "v3나 규칙 11·12가 p2보다 낫다/못하다"는 판단할 수 없어요.**
