## 역할
| 이름 | 역할 | 이번 주 최소 목표 (~10/16) | 튜토리얼 |
|---|---|---|---|
| **주희** | 판정 (4·6·7번) + 비는 부분 + 팀 조율 | 충전되면 판정 v3 평가 → main 합치기 | `docs/튜토리얼_주희.md` |
| **해준** | 연결 (1·2·3번, 파이프라인, 데모) + 5번 코드 | 판정 v3 변경 사항 확인, 여러 시험에 걸친 질문 묶기 | `docs/튜토리얼_해준.md` |
| **서현** | 5번 질문 프롬프트 (코딩 없음) | 질문 생성 프롬프트 v1 만들어 보기 | `docs/튜토리얼_서현.md` |
| **인선** | 상세 환자·발표 기획 (코딩 없음) | 상세 환자 1명 쓰고 판정하기 | `docs/튜토리얼_인선.md` |

해준이 5·6·7번 초안까지 만들어 둬서, 주희는 6·7번을 새로 만들지 않고 **해준 초안을 이어받아 다듬고 평가**해요.

## 전체 흐름 (코드 위치)
```
환자 설명
  ▼ [해준] 1번 환자 이해          src/agents/patient_profiler.py
  ▼ [해준] 2번 시험 검색          src/agents/trial_searcher.py   (나이·성별은 코드로 거름)
  ▼ [해준] 3번 기준 파싱          src/agents/criteria_parser.py
  ▼ [주희] 4번 판정              src/agents/matcher.py          (나이·임신은 코드 판정, 최종 판단은 코드 규칙)
  │   → data/handoff/<환자ID>.json  (형식: docs/HANDOFF.md)
  ▼ [서현 프롬프트 + 해준 코드] 5번 질문 생성   src/agents/question_generator.py
  ▼ [주희] 6번 재평가 (답변 반영)  src/agents/profile_updater.py → 4번 다시
  ▼ [주희] 7번 추천·설명          src/agents/recommender.py
  ▼ [해준 구현 / 인선 기획] 데모 화면   app.py   (streamlit run app.py)
```

## 짝
- **서현 ↔ 해준**: 서현 프롬프트를 해준이 `question_generator.py`에 넣어요
- **인선 ↔ 주희**: 인선의 상세 환자로 주희가 통과·탈락 정확도를 재요

## 공통 규칙
- **데이터 형식(`docs/HANDOFF.md`)을 바꿀 때는 먼저 알리기**
- **API 비용 드는 실행 전에 한 줄 알리기.** 연구실 모든 팀이 같은 잔액을 써요
- **API 키는 GitHub·노션·단톡방에 올리지 않기.** 키 파일 위치: 해준 코드는 프로젝트 맨 위 `.env`, 평가 도구(`eval/`)는 `eval/.env`
- 코드는 각자 브랜치에서 작업하고, main에 합치기 전에 한 명 이상 확인
- 1위 팀 원본 자료는 공유하지 않기 (분석만 공유)
