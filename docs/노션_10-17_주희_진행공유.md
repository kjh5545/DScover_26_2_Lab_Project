  - **안전장치**: AI가 기준을 빠뜨리거나 이상한 판정값을 내면 자동으로 "모름" 처리 (빠진 탈락 기준 때문에 "적격 가능"이 잘못 나오는 일 방지)
  - **5번 → 6번 연결 형식 결정**: 질문·답변·바뀐 판정을 handoff 파일 하나(`rounds`)에 라운드별로 쌓기. 해준님이 만들 `build_questions()` 모양도 정함
  - **6번 재평가 완성**: 답과 관련된 기준만 다시 판정하고, 질문을 마치면 전체를 한 번 다시 판정(`final_check`). 근거에 "Q1 답변: …"이 인용됨
  - **질문 루프 첫 실제 실행 (S004)**: 질문 9개로 혈뇨 검진 시험의 모름 4 → 1. 이때 찾은 문제 2개는 바로 고침, 1개는 남음 (아래 "막힌 것")
  - **인선님 상세 환자 검증 준비**: 시트가 올라오면 바로 돌릴 수 있게 시트 읽기·점검(무료)과 평가 스크립트를 만들어 둠
