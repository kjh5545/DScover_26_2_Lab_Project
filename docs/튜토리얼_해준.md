## Step 2. 여러 시험에 걸친 질문 묶기 (5번 코드, 여유 있으면)
지금 `app.py`는 시험 하나(`question_target`)를 골라 그 시험의 모름 기준으로 질문을 만들어요. 1위 팀처럼 **환자 단위로, 여러 시험에 공통으로 걸린 정보부터** 묻도록 바꾸는 게 목표예요.

```
handoff/<환자>.json
  → ① 질문 재료 모으기 (코드): 모든 후보 시험의 unknown 판정 + needed_info
       (부적격 시험, post_enrollment 항목은 제외)
  → ② 같은 정보 묶기 (코드): needed_info가 같으면 하나로, 걸린 시험 수 → 기준 수 순 정렬, 상위 3~5개
  → ③ 질문 문장 만들기 (LLM): 서현 프롬프트 (question_generator.py의 SYSTEM_PROMPT 자리)
  → questions/<환자>.json  (형식 제안: docs/HANDOFF.md 맨 아래)
```
- `needed_info` 문구가 시험마다 조금씩 다를 수 있어요 ("renal function" vs "creatinine"). 처음엔 같은 문구끼리만 묶어도 충분해요
- 서현님 프롬프트가 나오기 전엔 지금 있는 프롬프트로 흐름만 만들어 두면 돼요
