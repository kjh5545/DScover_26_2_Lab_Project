# 질문 루프(5~6번) 정리

> 최종 수정: 2026-10-17 · 주희
> 한 줄 요약: **"코드가 고르고 → AI가 묶어서 쓰고 → 코드가 검사"**하는 질문 코드를 완성하고 데모 화면(`app.py`)까지 연결했어요. 실제 AI로 돌려서 **질문 하나로 두 시험의 기준이 같이 풀리는 것**을 확인했어요.
> 해준님·서현님은 **7. 확인 부탁드려요**만 봐 주세요.

---

## 1. 흐름

```
[1~4번] run_intake → 판정표 (handoff 파일)
   ↓
[5번] next_round   : 질문 만들기 (아래 3번) → bundle["rounds"]에 추가
   ↓  환자 답변
[6번] reassess     : 답과 관련된 기준만 다시 판정 → 바뀐 판정 기록
   ↓  (5~6번 반복)
      final_check  : 질문을 끝내면 모든 기준을 한 번 더 판정
```

- 코드: `src/pipeline.py` (`next_round`, `reassess`, `final_check`), `src/question_builder.py` (질문 만들기)
- 데모 화면 `app.py`도 이 흐름으로 돌아요. 화면에 "어느 질문 답 때문에 판정이 바뀌었는지"와 질문·답변 기록이 나와요.

## 2. 저장 형식: handoff 파일 하나에 라운드별로 쌓기

```jsonc
"rounds": [{
  "round": 1,
  "questions": [{"id": "Q1", "text": "지금 드시는 약을 모두 알려 주세요.", "needed_info": "지금 먹는 약",
                 "resolves": [{"trial": "NCT04063540", "criteria": ["E3", "E6"]},
                              {"trial": "NCT07348783", "criteria": ["E4"]}],   // 이 답으로 다시 판정할 기준
                 "priority": 1}],
  "answers": [{"question_id": "Q1", "answer": "혈압약 하나 먹어요"}],          // 환자 말 그대로
  "changed": [{"trial": "NCT07348783", "criterion_id": "E4", "from": "unknown", "to": "pass", "source": ["Q1"]}]
}]                                                                            // 전체 재판정이면 source ["full"]
```

- 질문 ID는 라운드를 넘어 `Q1, Q2, ...` 통번호예요.
- "모르겠어요" 답도 그대로 저장해요. 판정은 모름으로 두고, 같은 기준은 다시 묻지 않아요.
- 프로필은 답을 받아도 다시 쓰지 않아요. 판정할 때 원문과 모든 답변을 같이 넘겨요.

## 3. 질문 만들기 (5번)

> **10/22 서현님 v2.3.3으로 바꿈** (아래 표가 지금 방식). 바뀐 것 2가지: 질문 순서는 AI가 정한 대로(판정 영향 → 공통성 → 시험별 균형), 답을 받았는데도 모름인 기준은 한 번 더 물을 수 있음. 실행 결과: `docs/발표자료_중간발표.md` 5절, `data/processed/detailed_eval/run_10-22_q-v2.3.3/`

| 단계 | 누가 | 하는 일 |
|---|---|---|
| ① 고르기 | 코드 | 모름인 기준만 모아요. 부적격 시험, 등록 후 확인 기준은 빼요. 물어본 기준은 답을 받았는데도 모름이면 한 번 더 후보로 넣고, 건너뛴 질문의 기준과 두 번 물은 기준은 빼요 |
| ② 묶고 쓰기 | AI (서현님 v2.3.3 규칙, review 출력은 뺌) | **기준 원문**을 보고 뜻이 같은 것끼리 묶어 질문을 쓰고, 질문마다 관련 기준(`resolves`)을 적고, 우선순위대로 정렬해요 (AI 호출 1번) |
| ③ 검사·정리 | 코드 | 없는 기준 번호와 중복을 빼고 5개로 잘라요. 순서는 AI가 정한 대로예요 (10/21까지는 "여러 시험 질문 먼저 → 시험별로 번갈아"로 코드가 다시 정렬했음) |

**이렇게 바꾼 이유** (해준님 PR #1을 합치면서 나온 문제 2가지)
- 예전에는 `needed_info` **글자가 똑같아야** 묶였어요. 시험마다 문구가 달라서("current medication list" vs "antihypertensive medication use") S005에서 두 시험에 걸친 질문이 0개였어요.
- 질문 쓰는 AI가 **기준 번호만** 받아서 내용을 몰랐어요.
- 글자 비교 묶기는 AI 없이 돌리는 무료 모드(`--no-llm`)에만 남겼어요.

**서현님 v2.1에서 바꾼 것** (규칙 문장은 그대로)
- 규칙 1: 질문 개수는 코드가 정해서 입력의 [질문 수]로 넘겨요.
- 규칙 2: "시험마다 표현이 달라도 묻는 내용이 같으면 묶기" 예시를 추가했어요.
- 규칙 9: 물어볼 기준은 코드가 미리 골라서 넘겨요.
- 규칙 11과 출력 형식: JSON으로 받아요. 질문하지 않은 기준과 이유는 `not_asked`에 적어요.
- **규칙 13 추가**: 이미 받은 답변으로 알 수 있는 내용은 다시 묻지 않기

## 4. 다시 판정하기 (6번)

- `reassess`: 답한 질문의 `resolves`에 있는 기준만 다시 판정해요. 판정에는 원문과 지금까지의 모든 답변이 들어가요.
- `final_check`: 질문을 끝내면 모든 기준을 한 번 더 판정해요. 부분 재판정이 놓친 것(환자가 묻지 않은 정보를 덧붙인 경우, 흔들린 판정)을 바로잡아요.
- 출력 검사: AI가 기준을 빠뜨리거나 이상한 판정값을 내면 모름으로 바꿔요(안전한 쪽).
- 답변이 있을 때만 붙는 판정 안내(`src/agents/matcher.py`의 `ANSWERS_HEADER`)
  - 답을 근거로 인용하기
  - "모르겠어요"면 모름 유지
  - **"Prior/이전"은 시험 등록 전을 뜻하고, 지금 문제로 이미 받은 검사도 포함** (10/17 추가, 아래 E2 결정)
  - 답변이 없을 때는 요청이 예전과 똑같아서 평가 결과(172/173)에 영향이 없어요.

## 5. 정한 것

| 항목 | 결정 | 이유 |
|---|---|---|
| 질문 저장 위치 | handoff 파일 안 `rounds` | 파일 하나라 판정과 질문이 어긋나지 않음. 평가와 데모가 같은 파일을 읽음 |
| 질문 만들기 방식 | 코드 고르기 → AI 묶고 쓰기 → 코드 검사 | 문제 2가지가 한 번에 풀림. 호출 수는 그대로(라운드당 1번, 약 $0.05) |
| 한 라운드 질문 수 | 5개 | 바꾸고 싶으면 말해 주세요 |
| 질문 끝낼 때 | `final_check` 필수 | 10/16 실행에서 부분 재판정이 같은 답을 탈락으로 잘못 판정 |
| **혈뇨 시험 E2** (NCT05646485, "최근 2년 안에 혈뇨 검사 이력 → 제외") | **짧은 설명만 있으면 모름, "3주 전 혈뇨로 CT를 찍었다" 같은 답이 오면 탈락** | "Prior"는 시험 등록 전을 뜻함. 이 시험은 증상 없는 고위험군 선별검사(`primaryPurpose: SCREENING`)라 이미 혈뇨 검사를 받은 사람을 빼려는 기준. 평가 세트 정답(모름)은 그대로. 상세 환자 S004도 설명에 "혈뇨 때문에"가 없어 정답은 모름(10/18 주희 재판정) |

## 8. 남은 문제

| 문제 | 상태 |
|---|---|
| 애매한 기준은 판정할 때마다 결과가 달라질 수 있음 (예: MRI 연구 I4가 통과 → 모름). 근거에 "연구팀 판단 필요"라고 쓰면서 판정은 통과로 내기도 함 | "근거에 판단 필요라고 쓰면 모름" 규칙을 넣을지 팀 논의 |
| 1라운드 질문이 한 시험에 몰릴 수 있음 (S004: 5개 중 4개가 혈뇨 시험) | 코드는 AI가 쓴 질문 안에서만 고를 수 있음. AI에게 질문을 넉넉히 받아 코드가 고르는 방식 검토 |
| "또는" 기준: 혈뇨 시험 I2(흡연)와 I3(직업 노출)는 하나만 맞으면 될 것 같은데, 지금은 둘 다 맞아야 하는 것처럼 계산 | 3번 기준 파싱과 최종 판단을 같이 바꿔야 해서 방식 논의 필요 |
| 질문 내용의 질: 특정 진단명 보존, 과거 투약 기간, 민감한 질문이 늘 뒤로 밀림 | 서현님께 v2.2 규칙 부탁 (별도 메시지) |
