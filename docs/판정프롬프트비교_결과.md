# 판정 프롬프트 비교 결과

모델(claude-sonnet-5-5)과 입력(환자 원문 + 프로필 + 기준)은 모두 같게 두고, **판정 프롬프트만** 바꿔서 정확도를 비교했어요. 조건마다 3회씩 돌렸어요(5조건 × 19케이스 × 3회 = 285건, 실제 비용 약 $2.3). 결과 파일은 `data/processed/judge_ablation/`(summary.md, changes.csv, criteria.csv)에 있어요.

- 조건: p0(규칙 없음) → p1(사전 실험 규칙 6개) → p2(+ 평가 세트 팀 결정, 수술 적합성, 추론 금지) → v3(+ 오류 분석 규칙) → v3_r1112(v3 + 보류한 규칙 11·12). 대조군(control)은 아직 하지 않았어요.
- 읽는 법: **기준 일치 (AI만)** = 프롬프트 효과만 본 점수(주 숫자), **통과·탈락** = 정답이 통과·탈락인 기준만 센 점수(주 숫자). **+코드**는 나이·임신 코드 판정을 더한 점수예요. 괄호는 3회 중 최소~최대예요.

### 표 3에서 보이는 큰 흐름

- **p0 → p1**: 평가 세트에서 고쳐진 11개 중 8개는 정답이 "모름"인데 p0가 기록에 없는 걸 "통과"로 단정하던 오류예요. p1의 규칙 1·6(기록에 없으면 "모름")이 이걸 줄였어요. 반대로 망가진 2개는 정답이 "등록 후 확인"인 동의·순응 기준이에요. p1에는 이걸 "등록 후 확인"으로 보내는 규칙이 아직 없어요.
- **p1 → p2**: 가장 큰 변화(평가 세트 149.7 → 169)예요. 바뀐 23개 중 17개는 동의서·참여 의사·순응·기대수명·연구자 판단·수술 적합성을 "등록 후 확인"으로 보내는 규칙 4 효과로 보여요(16개는 근거 문장이 규칙과 같고, 1개는 흔들림이 섞여 있어요). 5개는 "추론으로 탈락 확정 금지"(규칙 8) 효과로 추정돼요. 규칙 4와 규칙 8이 같은 단계에서 함께 들어와서, 둘의 효과를 따로 떼어 말할 수는 없어요.
- **p2 → v3**: 평가 세트 고쳐짐 2·망가짐 3으로 거의 비겼어요. 5개 중 4개가 흔들리는 기준이라 규칙 효과라고 말하기 어려워요. "추정 진단 사용 금지"(규칙 9)가 효과를 냈다고 단정할 근거는 이 실험에서 분명하지 않아요.
- **v3 → v3_r1112**: 상세 환자에서 규칙 11("다학제 논의·ATS/ERS 기준 충족이 진술돼야 함")이 효과를 낸 게 분명한 기준이 2개(#52, #54)예요. 나머지 변화는 흔들림이 섞여 있거나 추정이에요.

## 읽을 때 주의할 점

- **상세 환자는 두 명뿐**이에요(S004·S008). 기준 하나가 1/46 ≈ 2.2%포인트라서, 작은 차이는 우연일 수 있어요. p2·v3·v3_r1112의 3회 범위도 서로 겹쳐요(예: 평가 세트 p2 166~171, v3 169~171).
- **규칙 11·12가 상세 환자 S008에 대해 독립적인 검증인지는 확인이 필요해요.** 규칙 11·12는 "ATS/ERS 기준", "IPF 외 다른 간질성폐질환"처럼 IPF 환자(S008)에서 나올 법한 오류를 겨냥한 문장이에요. 상세 환자는 평가 세트보다는 덜 본 데이터이지만 일부는 프롬프트 개선에 쓰였기 때문에, 이 규칙을 만들 때 S008 결과를 봤다면 v3_r1112의 상세 환자 점수(45/46)는 독립 검증으로 보기 어려워요. 규칙 11·12를 만들 때 S008 결과를 본 적이 있는지 팀에서 확인해 주실 수 있을까요?
- **+코드**는 나이·임신을 코드가 바로잡은 점수예요. v3_r1112에서 AI만(170.7)과 +코드(171.7)가 1만큼 다른 건 영아의 "임신" 기준(#51)을 코드가 정답으로 바꿨기 때문으로 보여요.
- 본 실험 중 1건(p1 · 평가 세트 · S008_NCT07299695 · 3회차)은 모델 응답이 JSON 형식이 아니어서 한 번 실패했고, 같은 명령으로 그 1건만 다시 돌려 채웠어요(프롬프트·코드는 그대로).
- 상세 환자 케이스 이름이 평가 세트와 같아도(예: S004_NCT04369560) 데이터 종류를 나눠 채점해요(채점 버그 수정 후).

## 쉬운 말 요약

1. 규칙을 더할수록 점수가 올랐고, 가장 큰 도약은 p1 → p2(평가 세트 149.7 → 169)였어요. 동의·순응 같은 기준을 "등록 후 확인"으로 보내는 규칙과 "추론으로 단정하지 않는 규칙"이 가장 크게 효과를 냈어요.
2. v3와 v3_r1112의 차이는 작고 3회 범위가 겹쳐서, 규칙 효과인지 우연인지 이 실험만으로는 말하기 어려워요.
3. 평가 세트는 규칙을 만들 때 본 데이터라 독립 검증이 아니에요.
4. p1·p2는 예전 v1·v2 원문이 아니라, 기록(회의록·레이블 검토)을 보고 다시 나눈 프롬프트예요.
5. p0에도 판정 4단계 뜻풀이는 들어 있어서 완전한 백지는 아니에요.
6. 위 요약은 평가 세트와 S004·S008 결과 기준이에요. 새 상세 환자 4명(S002·S010·N001·N002) 독립 검증에서는 이 흐름이 이어지지 않았어요. 자세한 내용은 아래 "추가. 새 상세 환자 4명 독립 검증" 절을 보세요.

## 추가. 새 상세 환자 4명 독립 검증 (S002 · S010 · N001 · N002)

주희님이 만든 새 상세 환자 4명(케이스 8개, 기준 142개)으로, **같은 프롬프트 5가지**(p0 · p1 · p2 · v3 · v3_r1112)를 3회씩 돌린 결과예요. 프롬프트와 코드는 하나도 바꾸지 않았고 결과를 본 뒤에도 고치지 않았어요. 기존 상세 환자 S004·S008은 섞지 않고 **새 4명만** 따로 셌어요(위 표 1의 상세 환자 표와 숫자가 달라요). 새 결과 120건의 실제 비용은 약 $1.76이에요.

- 환자별: N001 69개, N002 30개, S002 21개, S010 22개. 숫자는 3회 평균이고 괄호는 최소~최대예요.
- **독립성의 한계:** S002·S010은 시험과 기준이 평가 세트와 같아서 환자 설명만 새것이에요(부분 독립). N001·N002는 새 질환이라 가장 독립적이에요. 다만 N002 설명에 "ATS quality criteria"가 들어 있어 규칙 11을 시험하려는 의도가 보여서 완전한 블라인드는 아니에요.

### 유형별 해석

- **T1 (9개) · T2 (7개)는 규칙이 의도대로 일한 경우예요.** p0·p1은 기록에 없는 걸 "통과"로 단정하거나 동의서를 "모름"으로 답했는데, p2부터 "명시 안 되면 모름"과 "동의·순응·연구자 판단은 등록 후 확인"(규칙 4)으로 정답이 됐어요. 근거 문장이 규칙 문장과 거의 같아서 규칙 효과가 분명해요. 다만 S002 E4·E9처럼 v3까지 틀리다가 v3_r1112에서야 고쳐진 기준도 있어요.
- **T3 (6개)는 규칙이 있는데도 AI가 놓친 진짜 오류예요.** 간 수치를 스크리닝 때 재는 기준(N001 NCT06863532 E6), 연구자 판단 기준(N001 NCT07082114 E5·E6), HbA1c를 스크리닝 때 재는 기준(I4) 등에서 "언급이 없다"며 모름이라고 답했어요. 정답은 규칙 4에 따라 "등록 후 확인"이에요.
- **T4a (7개)와 T4b (5개)가 통과·탈락 하락의 대부분이에요.** 정답은 "통과"인데 AI가 모름이라고 답했어요.
  - T4a 예: 제2형 당뇨라고 적혀 있는데 "제1형 당뇨 제외" 기준에서 "제1형이 명시적으로 배제되진 않았다", 폐경 후라고 적혀 있는데 "임신 여부가 명시되진 않았다"라고 답했어요.
  - T4b 예: "제2형 당뇨 진단 기준 충족"에 "9년 병력은 있지만 진단 기준 충족은 진술되지 않았다"(N001 I3, 규칙 11), "다른 원인의 갑상선기능항진증"에 "다른 원인이 배제됐다는 진술이 없다"(S002 E2, 규칙 12 효과로 추정)라고 답했어요. N001 I3은 v3_r1112에서 처음 틀렸고, S002 E2는 v3에서 이미 흔들리다가(통모모) v3_r1112에서 3회 모두 모름이 됐어요.
- **T5 (3개)는 AI 오류라고 단정하기 어려워요.** 정답이 팀 규칙과 어긋나 보여서 팀 확인이 필요해요(아래 "팀에 확인할 것").

### 팀에 확인할 것 (추정이에요 — 시트 판정을 제가 다시 판정한 게 아니에요)

1. **"통과" 판정이 팀 결정(명시되지 않으면 모름)보다 느슨했을 수 있어요.** T4a의 상당수(제2형 당뇨 → 제1형 아님, 폐경 후 → 임신 아님 등)는 사람이 상식으로 추론해서 "통과"로 둔 것으로 보여요. 팀 결정 2(평가 세트 v1.1)는 논리적으로 추론할 수 있어도 명시되지 않으면 모름이라고 했어요. 같은 기준으로 판정했다면 정답이 모름이 되어 규칙이 더 맞는 셈이에요. 어느 쪽이 팀 기준인지 정해야 해요.
2. **비슷한 기준인데 정답이 서로 달라요.** N001 I3 "제2형 당뇨 진단 기준 충족"은 통과인데, N002 I2 "GINA 2023 지침에 따른 천식 진단"은 모름이에요. 둘 다 "진단은 받았지만 어느 기준으로 진단했는지는 안 적혀 있다"는 같은 상황이에요.
3. **N002 E7 ("현재 단클론항체 치료 중", 정답 탈락)** 은 5개 조건 모두 3회 내내 "통과"라고 답했어요. 설명에는 "두필루맙 첫 주사가 다음 주로 예정"이라고만 적혀 있어서 AI는 "지금은 맞고 있지 않다"고 읽었어요. 정답이 탈락인 근거가 무엇인지 확인이 필요해요.
4. **피임 의사 기준(N001 NCT06863532 E22, NCT07082114 I7)** 은 정답이 통과인데 AI는 p2부터 "의사는 등록 후 확인"(규칙 4)이라고 답했어요. 팀 결정 1(동의·참여 의사·순응은 등록 후 확인)과 어긋나는지 확인이 필요해요.

### 쉬운 말 요약 (새 4명)

1. 새 4명에서는 규칙을 더할수록 점수가 계속 오르지 않았어요. 기준 일치는 p2가 가장 높고(125.3/142), v3(122.7)는 p2와 3회 범위가 겹치지만(124~126, 121~125) v3_r1112(121.3, 범위 121~122)는 겹치지 않고 p2보다 낮아요.
2. 규칙은 "정답이 모름·등록 후 확인인데 통과로 단정"하는 오류를 확실히 줄였어요. 반면 "정답이 통과인데 모름으로 답하는" 경우가 늘어서 통과·탈락 점수는 73.3 → 61.7로 내려갔어요.
3. 늘어난 오류의 상당수는 AI의 실수라기보다 시트의 "통과" 정답이 팀 결정보다 느슨했을 가능성이 있어요(추정). 정답 기준을 팀이 확인해야 해요.
4. 규칙 11·12(v3_r1112)는 새 4명에서 v3보다 나아지지 않았고, 일부 기준에서 통과를 모름으로 바꿨어요.
5. 환자가 4명뿐이고 S002·S010은 부분 독립이며 N002는 의도한 설계라서, 이 결과만으로 프롬프트를 확정하기는 어려워요. 결과를 보고 프롬프트를 고치지는 않았어요.
