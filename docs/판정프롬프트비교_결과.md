# 판정 프롬프트 비교 결과

모델(claude-sonnet-5-5)과 입력(환자 원문 + 프로필 + 기준)은 모두 같게 두고, **판정 프롬프트만** 바꿔서 정확도를 비교했어요. 조건마다 3회씩 돌렸어요(5조건 × 19케이스 × 3회 = 285건, 실제 비용 약 $2.3). 결과 파일은 `data/processed/judge_ablation/`(summary.md, changes.csv, criteria.csv)에 있어요.

- 조건: p0(규칙 없음) → p1(사전 실험 규칙 6개) → p2(+ 평가 세트 팀 결정, 수술 적합성, 추론 금지) → v3(+ 오류 분석 규칙) → v3_r1112(v3 + 보류한 규칙 11·12). 대조군(control)은 아직 하지 않았어요.
- 읽는 법: **기준 일치 (AI만)** = 프롬프트 효과만 본 점수(주 숫자), **통과·탈락** = 정답이 통과·탈락인 기준만 센 점수(주 숫자). **+코드**는 나이·임신 코드 판정을 더한 점수예요. 괄호는 3회 중 최소~최대예요.

### 표 3에서 보이는 큰 흐름

- **p0 → p1**: 평가 세트에서 고쳐진 11개 중 8개는 정답이 "모름"인데 p0가 기록에 없는 걸 "통과"로 단정하던 오류예요. p1의 규칙 1·6(기록에 없으면 "모름")이 이걸 줄였어요. 반대로 망가진 2개는 정답이 "등록 후 확인"인 동의·순응 기준이에요. p1에는 이걸 "등록 후 확인"으로 보내는 규칙이 아직 없어요.
- **p1 → p2**: 가장 큰 변화(평가 세트 149.7 → 169)예요. 바뀐 23개 중 17개는 동의서·참여 의사·순응·기대수명·연구자 판단·수술 적합성을 "등록 후 확인"으로 보내는 규칙 4 효과로 보여요(16개는 근거 문장이 규칙과 같고, 1개는 흔들림이 섞여 있어요). 5개는 "추론으로 탈락 확정 금지"(규칙 8) 효과로 추정돼요. 규칙 4와 규칙 8이 같은 단계에서 함께 들어와서, 둘의 효과를 따로 떼어 말할 수는 없어요.
- **p2 → v3**: 평가 세트 고쳐짐 2·망가짐 3으로 거의 비겼어요. 5개 중 4개가 흔들리는 기준이라 규칙 효과라고 말하기 어려워요. "추정 진단 사용 금지"(규칙 9)가 효과를 냈다고 단정할 근거는 이 실험에서 분명하지 않아요.
- **v3 → v3_r1112**: 상세 환자에서 규칙 11("다학제 논의·ATS/ERS 기준 충족이 진술돼야 함")이 효과를 낸 게 분명한 기준이 2개(#52, #54)예요. 나머지 변화는 흔들림이 섞여 있거나 추정이에요.

- **상세 환자는 두 명뿐**이에요(S004·S008). 기준 하나가 1/46 ≈ 2.2%포인트라서, 작은 차이는 우연일 수 있어요. p2·v3·v3_r1112의 3회 범위도 서로 겹쳐요(예: 평가 세트 p2 166~171, v3 169~171).
- **규칙 11·12가 상세 환자 S008에 대해 독립적인 검증인지는 확인이 필요해요.** 규칙 11·12는 "ATS/ERS 기준", "IPF 외 다른 간질성폐질환"처럼 IPF 환자(S008)에서 나올 법한 오류를 겨냥한 문장이에요. 상세 환자는 평가 세트보다는 덜 본 데이터이지만 일부는 프롬프트 개선에 쓰였기 때문에, 이 규칙을 만들 때 S008 결과를 봤다면 v3_r1112의 상세 환자 점수(45/46)는 독립 검증으로 보기 어려워요. 규칙 11·12를 만들 때 S008 결과를 본 적이 있는지 팀에서 확인해 주실 수 있을까요?
- **+코드**는 나이·임신을 코드가 바로잡은 점수예요. v3_r1112에서 AI만(170.7)과 +코드(171.7)가 1만큼 다른 건 영아의 "임신" 기준(#51)을 코드가 정답으로 바꿨기 때문으로 보여요.
- 본 실험 중 1건(p1 · 평가 세트 · S008_NCT07299695 · 3회차)은 모델 응답이 JSON 형식이 아니어서 한 번 실패했고, 같은 명령으로 그 1건만 다시 돌려 채웠어요(프롬프트·코드는 그대로).
- 상세 환자 케이스 이름이 평가 세트와 같아도(예: S004_NCT04369560) 데이터 종류를 나눠 채점해요(채점 버그 수정 후).

## 쉬운 말 요약

1. 규칙을 더할수록 점수가 올랐고, 가장 큰 도약은 p1 → p2(평가 세트 149.7 → 169)였어요. 동의·순응 같은 기준을 "등록 후 확인"으로 보내는 규칙과 "추론으로 단정하지 않는 규칙"이 가장 크게 효과를 냈어요.
2. v3와 v3_r1112의 차이는 작고 3회 범위가 겹쳐서, 규칙 효과인지 우연인지 이 실험만으로는 말하기 어려워요.
3. 평가 세트는 규칙을 만들 때 본 데이터라 독립 검증이 아니에요.
4. p1·p2는 예전 v1·v2 원문이 아니라, 기록(회의록·레이블 검토)을 보고 다시 나눈 프롬프트예요.
5. p0에도 판정 4단계 뜻풀이는 들어 있어서 완전한 백지는 아니에요.
