# 서현 튜토리얼: 질문 생성 프롬프트 만들기 (코딩 없음)

> 역할: 5번 질문 생성 에이전트의 **프롬프트 설계**. 코드는 해준님이 붙여요
> 다음 점검: 2026-10-16 (금), 노션 공유
> 예상 시간: 2~3시간 (시험 기간이라 최소 목표만 해도 충분해요)

## 무엇을 만드나요
4번 판정 에이전트가 "모름"으로 판정한 기준들을 받아서, **환자에게 물어볼 질문 3~5개**를 만드는 프롬프트예요.

주희가 판정 프롬프트를 만든 것과 같은 방식이에요. **웹 채팅(Claude, ChatGPT 등)에 프롬프트를 붙여 넣고 → 결과를 보고 → 규칙을 고치는 것**을 반복하면 돼요. 다듬어진 프롬프트는 해준님이 코드에 넣어요.

## 이번 주 목표
| 구분 | 할 일 |
|---|---|
| **최소** | Step 1~3: 아래 프롬프트 v0를 돌려 보고, 체크리스트로 점검하고, 고친 v1 만들기 |
| 여유 있으면 | Step 4: 다른 환자 입력으로도 v1이 통하는지 확인 |

---

## Step 0. 알아 둘 것 (10분)
**왜 질문을 "묶어야" 하나요?**
S004(68세 남성, 방광암 의심) 환자는 후보 시험 2개에서 "모름"인 기준이 **14개**예요. 레이블할 때는 기준마다 질문을 하나씩 써서 질문도 14개였어요. 하지만 실제 환자에게 14개를 다 물을 수는 없어요. 그래서 **3~5개로 묶고, 중요한 것부터** 묻는 게 목표예요.

**1위 팀은 이렇게 했어요**
- 여러 시험에 공통으로 걸린 정보부터 묻기
- 한 질문에는 정보 하나만
- 검사 수치는 환자 기억으로 묻지 않기 (예: "크레아티닌 수치가 몇이었나요?" 대신 "최근 신장 기능 검사를 받은 적 있나요?")
- 적격인지 아닌지는 질문에서 말하지 않기
- 나이·성별·임신 여부처럼 거의 모든 시험이 묻는 기본 정보는 처음에 확인

**판정 단어 복습**: 통과 / 탈락 / 모름(물어보면 알 수 있음) / 등록 후 확인(지원해야 알 수 있음, 질문하지 않음)

---

## Step 1. 프롬프트 v0 돌려 보기 (30분)
새 대화를 열고 아래 코드 블록을 **통째로** 붙여 넣으세요.

```
당신은 임상시험 사전 스크리닝에서 환자에게 확인 질문을 만드는 담당자입니다.
아래는 한 환자의 후보 임상시험들에서 "모름"으로 판정된 기준 목록입니다. 이 기준들을 확인하기 위해 환자에게 물어볼 질문을 만드세요.

[질문 규칙]
1. 질문은 최대 5개입니다. 판정에 영향이 큰 질문부터 순서대로 쓰세요.
2. 여러 시험이나 여러 기준에 공통으로 필요한 정보는 질문 하나로 묶으세요. 걸린 시험·기준이 많은 정보일수록 먼저 묻습니다.
3. 한 질문에는 한 가지 주제만 담으세요. 한 질문은 두 문장을 넘기지 마세요.
4. 환자가 이해할 수 있는 쉬운 한국어로 쓰세요. 전문 용어는 풀어서 쓰세요.
5. 검사 수치를 기억으로 묻지 마세요. 대신 검사를 받은 적이 있는지, 결과지가 있는지를 물으세요.
6. 진단명보다 증상이나 경험을 물으세요. (예: "OO병 진단을 받았나요?"보다 "OO 증상이 있었나요?"가 더 답하기 쉬우면 증상으로)
7. 환자에게 적격인지 아닌지 말하지 마세요.
8. 민감한 질문(임신, 정신 건강, 법적 신분 등)은 부드럽게 쓰고 다른 질문과 묶지 마세요.
9. 질문할 가치가 낮은 기준(예: 의사가 판단할 항목)은 질문하지 말고, "질문하지 않은 기준"에 이유와 함께 적으세요.

[출력 형식]
1. 질문 목록: 번호. 질문 — 해결되는 기준 (시험 번호와 기준 ID)
2. 질문하지 않은 기준: 기준 ID — 이유

[환자]
A 68-year-old man with a long smoking history presents with painless gross hematuria. CT urography reveals a mass in the bladder wall.

[시험 1: NCT04369560 · 방광벽 MRI로 방광암 병기 결정]
I3. A papillary tumor identified by cystoscopy that has been scheduled for TURBT OR histologically proven MIBC that is clinically localized and amenable to surgical resection with curative intent.
I4. Performance status of ECOG 0 or 1
I5. Normal renal function as defined as creatinine less than 1.5 x institutional upper limit of normal (ULN) OR creatinine clearance greater than or equal to 50 mL/min/1.73 m2 by Cockcroft-Gault formula for subjects with creatinine levels greater than or equal to 1.5 x ULN.
E1. Severe hypersensitivity reaction to gadobutrol or ferumoxytol.
E2. Severe claustrophobia that will prevent completion of the MRI study.
E3. Any MRI-non-compatible implanted device, prosthetic or pacemaker.
E4. Known or suspected metastatic disease.
E6. Untreated urinary tract infection
E7. Known urethral stricture disease that would prohibit placement of foley catheter.
E8. Any other conditions considered as unacceptable risk by the treating physician

[시험 2: NCT05646485 · 방광암 선별검사 (고위험군)]
I2. Smoking: ≥15 pack-year smoking history
I3. Occupation: ≥ 15 years of occupational exposures including: textile worker, painter, dry cleaners
E1. Prior history of bladder, kidney, or prostate cancer
E2. Prior evaluation of micro or gross hematuria within the last 2 years
```

답변을 받으면 그대로 복사해서 메모장이나 노션에 붙여 두세요.

## Step 2. 체크리스트로 점검하기 (30분)
답변을 보면서 아래 표를 채우세요. 노션에 표를 복사해서 쓰면 편해요.

| # | 확인할 것 | v0 결과 | 메모 |
|---|---|---|---|
| 1 | 질문이 5개 이하인가? | | |
| 2 | 한 질문에 주제가 하나인가? (예: "흡연량과 직업"을 한 질문에 섞지 않았나) | | |
| 3 | 두 시험에 공통으로 필요한 정보를 묶었나? (예: 시험 1 E4 전이 + 시험 2 E1 암 병력 → "이전 암 진단·전이" 질문 하나) | | |
| 4 | 중요한 순서인가? | | |
| 5 | 환자가 알아들을 말인가? (TURBT, ECOG, 크레아티닌 같은 용어를 풀었나) | | |
| 6 | 검사 수치를 기억으로 묻지 않았나? | | |
| 7 | 적격 여부를 말하지 않았나? | | |
| 8 | 질문하지 않은 기준과 이유가 그럴듯한가? (예: E8 "의사가 판단" → 질문 안 함) | | |
| 9 | 지어낸 내용이 없나? (환자 설명에 없는 사실을 전제로 묻지 않았나) | | |

**비교해 볼 사람 질문**: 레이블할 때 쓴 질문 중 몇 개예요. AI 질문이 이것보다 쉽고 짧은지 비교해 보세요.
- "방광내시경에서 유두상 종양이 발견되어 경요도 방광종양절제술(TURBT)이 예정되어 있거나, 조직검사로 근침윤성 방광암(MIBC)이 확인된 적이 있나요?" → 너무 길고 어려워요. 둘로 나누거나 쉽게 바꿀 수 있을까요?
- "평소 일상생활을 거의 제한 없이 수행할 수 있나요?" (ECOG를 쉽게 바꾼 좋은 예)
- "하루에 평균 몇 갑씩, 몇 년 동안 담배를 피우셨나요?"

## Step 3. 규칙을 고쳐서 v1 만들기 (1시간)
체크리스트에서 아쉬운 점이 나오면 `[질문 규칙]`에 규칙을 추가하거나 고치고, **새 대화**에서 다시 돌려요. 같은 대화에서 하면 앞 답변의 영향을 받아요.

고칠 때 팁
- **한 번에 규칙 1~2개만 바꾸세요.** 여러 개를 한꺼번에 바꾸면 무엇이 효과가 있었는지 알 수 없어요
- 규칙을 바꿀 때마다 v0, v1, v2처럼 이름을 붙이고, 무엇을 왜 바꿨는지 한 줄 적어 두세요
- 예시를 하나 넣어 주면 AI가 훨씬 잘 따라요 (예: "좋은 질문 예: 평소 일상생활을 거의 제한 없이 하실 수 있나요?")

## Step 4. 다른 환자로도 확인하기 (여유 있으면)
v1이 S004에만 맞춘 규칙이 아닌지 보려면 다른 환자로 돌려 봐요. 프롬프트의 `[환자]`와 `[시험]` 부분만 바꾸면 돼요. 입력은 `goldset/평가세트_v1.md`에서 각 케이스의 "정답 = 모름"인 기준만 골라 복사하면 돼요. 추천: **S008(60세 여성, 폐섬유증 의심)**, 시험 2개.

해준님이 파이프라인 결과 파일(`data/handoff/S005.json`)을 올려 주면, 거기서 `verdict`가 `unknown`인 항목과 `needed_info`를 그대로 입력으로 써도 돼요.
