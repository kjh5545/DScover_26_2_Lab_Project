## 두 시험 비교
**S005에게 어느 쪽을 먼저 추천하겠습니까? 이유는?**
- A: 국적이 프랑스로 한정되지 않으며, 개인 정보에 대한 민감한 질문이 필요하지 않고 개인이 겪고 있는 증상들에 대한 정보만 얻으면 바로 임상에 도입될 수 있음

**확인 질문을 하나만 할 수 있다면 무엇을 묻겠습니까? 이유는?**
- 증상을 겪게 된 기간: 기간에 대해 묻는 질문이 많은 것에 비해 기간 정보가 부족한 것 같아서


**회의 안건으로 가져갈 것**

1. 판정 단어: 통과 / 탈락 / 모름 // 등록 후 확인을 추가?
2. 증상은 맞지만 진단 기록이 없을 때의 원칙 (추정 충족 단계를 둘지)
3. 질문을 기준마다 따로 만들지, 하나로 묶어서 여러 기준을 해결할지
4. 환자 눈높이 용어 변환
5. 좋은 질문의 기준: 판가름이 명확이 나게 하는 것 / 답 하나로 해결되는 기준 수가 많은 것
