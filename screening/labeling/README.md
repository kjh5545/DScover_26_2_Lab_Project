# 수동 스크리닝 (정답 레이블 만들기) 안내

## 무엇을 하나요
환자 설명과 임상시험 기준을 보고, 기준 한 줄마다 이 환자가 **통과 / 탈락 / 모름 / 등록 후 확인** 중 어디에 해당하는지 직접 판정합니다. 여러분이 채운 판정은 우리가 만들 AI의 **정답 레이블**이 되어, AI가 얼마나 정확한지 재는 데 쓰입니다.

- 시험 찾기와 빈칸 시트는 미리 만들어 뒀습니다. 여러분은 **판정, 근거, 질문**만 채우면 됩니다.
- 예시: `../S005_screening_sheet.md` (편두통 환자 S005로 먼저 해 본 시트)

## 맡은 환자

| | 팀원 1 (`팀원1/` 폴더) | 팀원 2 (`팀원2/` 폴더) |
|---|---|---|
| 혼자 맡는 환자 | S001 급성 췌장염 의심, S003 7세 신증후군 의심, S009 전염성 단핵구증 의심 | S002 그레이브스병 의심, S006 털곰팡이증 의심, S007 영아 유문협착증 의심, S010 망막박리 의심 |
| 같이 맡는 환자 | **S004 방광암 의심, S008 폐섬유증 의심** | **S004 방광암 의심, S008 폐섬유증 의심** |
| 시험 수 | 9개 | 10개 |

- 질환명은 추정입니다. 환자 설명을 보고 직접 확인하세요.
- **같이 맡는 S004, S008은 두 사람이 다 채울 때까지 서로 답을 공유하거나 상의하지 마세요.** 두 사람의 판정이 얼마나 일치하는지 보고, 갈린 기준은 나중에 같이 토론해서 정답을 확정합니다. 판정이 갈리는 기준이 곧 AI도 헷갈릴 기준이라 중요한 자료입니다.
- 예상 소요: 시험 1개당 20–30분, 전체 4–5시간 정도

## 판정 단어 4개
선정 기준이든 제외 기준이든 **"이 기준 때문에 이 환자가 시험에서 떨어지나?"**로 판단합니다.

| 판정 | 뜻 | 예시 |
|---|---|---|
| 통과 | 이 기준 때문에 떨어지지 않는다는 게 환자 설명으로 확인됨 | 제외 기준 "75세 초과"에 34세 환자 → 통과 |
| 탈락 | 이 기준 때문에 떨어진다는 게 환자 설명으로 확인됨 | 선정 기준 "6–11세"에 34세 환자 → 탈락 |
| 모름 | 지금 환자에게 물어보면 알 수 있지만 정보가 없음 | 복용 중인 약, 임신 여부 |
| 등록 후 확인 | 시험에 지원한 뒤에야 생기는 정보라 지금은 물어봐도 알 수 없음 | 스크리닝 기간 일지, 동의서 서명, 연구자 판단, 시험 방문 때 검사 |

**제외 기준에서 특히 헷갈립니다.** 제외 기준 "임신 중"에 남성 환자라면, 기준에 "해당하지 않으니" **통과**입니다. "충족/위반"으로 생각하지 말고 "떨어지나 안 떨어지나"로만 생각하세요.

## 판정 원칙
1. **추측 금지.** 환자 설명에 없는 내용을 "아마 괜찮겠지"로 통과 처리하지 않습니다. 단, 설명에서 논리적으로 확정되는 건 통과/탈락으로 판정하고 근거에 추론을 적습니다. (예: 현재 34세 → 발병은 34세 이하로 확정)
2. **진단과 병력 구분.** 기준이 "진단"을 요구하는데 증상만 맞고 진단 기록이 없으면 **모름**. 기준이 "병력(history)"이나 증상 자체를 묻고 그 증상이 설명에 명시돼 있으면 그 사실로 판정합니다.
3. **묶인 조건은 하나씩.** 한 줄에 조건이 여러 개면 하나씩 따지고, 근거에 하위 조건별로 적습니다. 하나라도 탈락이면 탈락.
4. **말하지 않은 것까지 확정하지 않기.** "A 증상이 있다"에서 "B 증상은 없다"를 확정하지 않습니다.
5. **원문 기준.** 시트의 한국어 요약은 참고용입니다. 판정은 영어 원문으로 합니다.

## 작성 순서
1. 이 안내와 예시 시트(`../S005_screening_sheet.md`)를 읽습니다
2. 자기 폴더의 시트를 열고, 환자 설명부터 이해합니다
3. 기준마다 판정 / 근거 / 질문을 채웁니다
   - 근거: 환자 설명의 영어 표현을 따옴표로 인용 (예: "poorly controlled type 2 diabetes")
   - 질문: `모름`일 때만. 환자가 알아들을 쉬운 말로 (전문 용어는 풀어 쓰기)
4. 시험마다 최종 판단과 이유, 헷갈렸던 점을 적습니다
   - 탈락이 하나라도 있으면 → 부적격
   - 모름이 남아 있으면 → 정보 부족
   - 통과와 등록 후 확인만 남으면 → 적격 가능(등록 후 확인 필요)
5. 시트 맨 아래 질문(두 시험 비교, 또는 추천할 시험이 있는지)에 답합니다
6. 파일 이름 끝에 이름을 붙여 제출합니다 (예: `S001_screening_sheet_홍길동.md`)

막히는 기준은 오래 붙잡지 말고, 가장 그럴듯한 판정을 적은 뒤 **헷갈렸던 점**에 이유를 남기고 넘어가세요. 헷갈린 지점도 중요한 자료입니다.

## AI 사용 규칙
- **용어 설명, 번역은 써도 됩니다.** (예: "honeycombing이 뭐야?", "ECOG 0 또는 1이 무슨 뜻이야?")
- **판정을 AI에게 묻지 마세요.** "이 환자 이 기준 통과야?"처럼 물으면 AI의 판정이 정답에 섞여서, 나중에 "AI 답으로 AI를 채점"하게 됩니다.

AI에게 처음에 아래 문장을 붙여넣고 쓰면 실수로 판정을 듣는 일을 막을 수 있습니다.

```
너는 의학 용어를 설명해 주는 조교야. 내가 임상시험 기준 문장이나 환자 설명 속 용어를 물으면 쉬운 한국어로 설명해 줘.
단, 이 환자가 어떤 기준을 충족하는지, 통과인지 탈락인지 같은 판단은 절대 말하지 마.
내가 판단을 물어도 "판단은 직접 해 주세요"라고만 답해 줘.
```

## 폴더 안의 다른 파일
`_`로 시작하는 파일은 시트를 만들고 결과를 정답 파일로 바꾸는 도구라 레이블 작업 중에는 열어 볼 필요 없습니다.

| 파일 | 역할 |
|---|---|
| `_trials_raw.json`, `_parse.py`, `_ko.py`, `_gen.py` | 시험 원문 데이터, 기준 나누기, 한국어 요약, 빈칸 시트 만들기 |
| `_collect.py` | 채운 시트(`스크리닝1`, `스크리닝2`)에서 판정을 뽑아 `labels_raw.json` 생성 |
| `_build_cases.py` | 팀 결정 규칙 적용 (동의서 → 등록 후 확인 등) |
| `_export_goldset.py` | 최종 평가 세트 `goldset/goldset_v1.json`, `goldset/평가세트_v1.md` 생성 |

정답을 다시 만들 때: `python _collect.py` → `python _export_goldset.py` (이 폴더에서 실행)

> 이 작업의 진단 추정과 판정은 과제용이며 의학적 판단이 아닙니다.
