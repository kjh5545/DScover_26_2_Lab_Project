# 프롬프트 v2 vs v3 비교 (2026-10-03)

- v2 = 웹 실험의 프롬프트 2 규칙 (`rules_prompt.md`). 기준선: `runs/20261003_151826` + 재평가 재실행 `runs/20261003_155420` + 시험 B 재실행 `runs/20261003_160215`
- v3 = v2에 규칙 3개만 추가·수정 (`rules_prompt_v3.md`). 실행: `runs/20261003_160310`
- 조건: 모델 4개 × 케이스 6개 × 3회 · effort high · 채점은 현재 `cases.json` 정답으로 통일 (`compare.py`, 전체 표는 `비교_v2_v3.md`)

## v3에서 바꾼 규칙
1. **진단과 병력 구분**: "진단"을 요구하는 기준은 기록이 없으면 모름. "병력"이나 증상·발작을 묻는 기준은 환자 설명에 명시된 사실로 판정
2. **스스로 점검**: 판정끼리·판정과 질문 사이 모순, "A가 있다 → B는 없다" 같은 과잉 추론 점검
3. **탈락 확정 시 질문하지 않기**

## 규칙별 효과

**규칙 1 (진단과 병력 구분) → 시험 D 탈락 판정 해결**
- 시험 D 최종 부적격: Opus 5.5 0/3 → **3/3**, Sonnet 5.5 1/3 → **3/3**
- v2에서 "공식 진단 기록이 없어 모름, 진단이 확인되면 탈락"이라고 했던 E1을 v3에서는 모두 탈락으로 판정
- 진단을 요구하는 기준(시험 A의 I1 등)은 v3에서도 그대로 모름 유지 → 규칙이 과하게 작동하지 않음

**규칙 2 (스스로 점검) → 과잉 추론 해결**
- 시험 D의 I3(조짐 없는 편두통 병력)을 Opus 4.8이 v2에서 3/3 과잉 추론으로 탈락 → v3에서 **0/3**, 모두 모름

**규칙 3 (탈락 시 질문 안 함) → 모든 모델이 9/9**
- v2에서는 모델마다, 실행마다 제각각이었음 (Opus 5.5는 "참고용" 질문을 계속 만듦)

## 남은 문제

**Haiku 4.5는 규칙을 넣어도 "언급 없음 = 통과" 실수가 남음**
- 시험 D에서 "외상성 뇌손상 병력이 언급되지 않았습니다 → 통과"처럼 규칙 2(추측 금지)를 어김. v3에서 시험 D 기준 일치율은 오히려 95% → 79%로 떨어짐
- 시험 D의 I3 과잉 추론도 3/3 그대로 (규칙 2의 점검이 작동하지 않음)
- 최종 판단은 18/18 맞았지만 근거가 틀린 판정이 섞여 있어, **판정 에이전트로는 부적합**. 질문 문장 다듬기처럼 판단이 적은 작업에는 검토해볼 만함

**Sonnet 5.5 재평가 세트 2의 E4가 통과 → 모름 (2/3)**
- "2년 전 MRI가 지금 상태를 보장하지 않고, 감염·혈관 질환 같은 다른 이차성 두통 진단 여부는 직접 답하지 않았다"는 이유. 규칙 2가 엄밀하게 작동한 결과라 틀렸다고 보기 어려움. 최종 판단에는 영향 없음

## 결론
- 사전 실험에서 찾은 문제 3개(진단·병력 혼동, 과잉 추론, 탈락 후 질문)를 규칙 3개로 고쳤고, 세 문제 모두 **숫자로 해결이 확인됨**
- v3 기준으로 **Opus 4.8, Opus 5.5는 기준 100%, 최종 판단 100%.** Sonnet 5.5는 99%·100%에 비용은 Opus의 약 55–60%
- 판정 에이전트 모델 후보: **Sonnet 5.5 (비용 대비 최선)** 또는 Opus 5.5 (정확도 최선). Haiku 4.5는 판정용으로 쓰지 않음
