# STEP 6 실행 전 최종 점검표

아래 항목을 모두 확인한 뒤 유료 실행을 승인한다. ● 표시는 실행기가 자동으로 차단하는 항목이다.

## A. 사람의 확인이 필요한 항목

| 상태 | 항목 | 담당 |
|---|---|---|
| ☐ | M4a 고영향 기준 정의를 팀이 검토하고 승인하였다 ● | |
| ☐ | 인선 님·주희 님이 판정 프롬프트·코드 변경 예정을 확인하였다 ● | |
| ☐ | "기억나지 않아요" 처리, 판정 규칙 11·12의 파일럿 기준을 현행으로 고정하기로 합의하였다 | |
| ☐ | 사전 주석자, 평가자, 조정자, 관리자를 지정하였다 ● | |
| ☐ | 담당자별 정답 노출 여부와 범위를 기록하였다 ● | |
| ☐ | 관리자는 채점에 참여하지 않는다 | |
| ☐ | 공용 API 키 사용과 예상 비용을 팀에 공지하였다 | |
| ☐ | 유료 실행을 승인하였다 | |

## B. 사전 주석

| 상태 | 항목 |
|---|---|
| ☐ | S004 후보 13개, S008 후보 23개의 주석을 완료하였다 ● |
| ☐ | 공유정보 군집 주석을 완료하였다 ● |
| ☐ | 주석 작성 중 정답과 생성 질문을 보지 않았거나, 노출을 기록하였다 |
| ☐ | 불일치를 조정하고 기록하였다 |
| ☐ | `lock-annotation`으로 잠갔다 ● |

평가 모집단은 **후보 36개**이다. 전체 기준 46개가 아니다. 비후보 10개는 M8d의 분모로만 쓴다.

## C. 환경

| 상태 | 항목 |
|---|---|
| ☐ | 브랜치 `exp/question-ablation`, 실험 폴더 밖 변경 없음 ● |
| ☐ | `.env`가 저장소 최상위에 있고 Git에 포함되지 않음 |
| ☐ | `pilot_lock.json`과 현재 상태 일치 (`run_pilot.py check`) ● |
| ☐ | 원격 `main`의 판정 코드 변경 여부를 확인하고, 변경이 있어도 이 브랜치는 고정 커밋을 유지하기로 하였다 |
| ☐ | 테스트 53 + 28 + 47건 통과 |
| ☐ | API 키로 모델 ID 사용 가능 여부와 오늘자 가격을 확인하였다 |

## D. 실행 중 중단 조건

| 조건 | 대응 |
|---|---|
| API 오류 3회 연속 | 자동 중단. 원인 확인 후 재실행 |
| 고정 값 변경 | 자동 차단. 변경 내용 확인 |
| 질문 단계 비용이 추정 상한의 1.5배 초과 | 후속 단계 전 재승인 |
| 특정 조건의 형식 실패 또는 거부 다수 | 기록하고 보고. 프롬프트는 수정하지 않는다 |
| A2와 C_full의 출력이 사실상 같음 | 결과로 기록. 프롬프트는 수정하지 않는다 |

## E. 실행 후 금지 사항

- 결과를 보고 프롬프트나 주석을 수정하지 않는다.
- 채점 잠금 전에 `sealed/`, `downstream/`, `answers/`를 평가자에게 보여 주지 않는다.
- 파일럿 결과를 입증이나 독립 평가로 표현하지 않는다.
