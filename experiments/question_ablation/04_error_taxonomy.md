# 04. 오류 유형 분류표

평가자용 문서이다. 코드는 `evaluation/scoring_schema.json`과 일치한다. 예시는 설명을 위한 **가상 사례**이다.

## 사용 규칙

- 코드는 FAIL, PARTIAL, NONE, INVALID 판정의 이유를 적는 데 쓴다. PASS에는 쓰지 않는다.
- 연결 채점표의 `error_codes`에는 해당 코드를 모두 `;`로 구분해 적는다. 예: `F1;C2`
- 질문 채점표의 오류 칸에는 주된 코드 하나를 적는다.
- 해당 코드가 없으면 가장 가까운 코드를 쓰고 `rationale`에 이유를 적는다.
- `needs_review`는 확신이 없거나 코드가 맞지 않을 때 표시한다.

## F. 원문 조건 왜곡

질문이 다룬 조건의 의미가 기준 원문과 달라진 경우이다. **언급하지 않은 것은 F가 아니다.**

| 코드 | 이름 | 가상 예시: 원문 → 질문 |
|---|---|---|
| `F1` | 기간·기준 시점 왜곡 | within 12 months → "최근 6개월 안에" |
| `F2` | 수치·단위 왜곡 | eGFR < 45 → "신장 수치가 60 미만인가요?" |
| `F3` | 빈도·집계 방식 왜곡 | 달마다 4일 이상 → "월평균 4일 이상" |
| `F4` | 진단명·질환 범위 왜곡 | cluster headache → "만성 군발두통" |
| `F5` | 약물명·용량 왜곡 | >20mg daily → "고용량" |
| `F6` | 투여 경로 왜곡 | 경로 제한 없음 → "드시는 약" |
| `F7` | AND/OR·예외 논리 왜곡 | A and B → "A나 B" |
| `F8` | 적용 대상·신체 부위 왜곡 | bladder tumor → "종양" |
| `F9` | 원문에 없는 조건 추가 | prior evaluation → "이번 증상 이전의 검사" |
| `F10` | 원인 관계 왜곡 | worsening due to heart failure → "악화가 있었나요?" |

## A. 근거 없는 가정

짧은 환자 설명에 없는 사실을 일어난 것으로 전제한 경우이다. 중립적 확인이나 "~라면" 조건문은 가정이 아니다.

| 코드 | 이름 | 가상 예시 |
|---|---|---|
| `A1` | 진단 전제 | 진단 정보가 없는데 "폐섬유증 진단 후 어떤 치료를 받았나요?" |
| `A2` | 치료·검사 전제 | 이력 정보가 없는데 "비만 수술은 어느 병원에서 받으셨나요?" |
| `A3` | 증상·소견의 확진 전제 | 혈뇨만 있는데 "방광암 수술 일정은 언제인가요?" |
| `A4` | 미래·가능 사실의 기정사실화 | 예약 전인데 "이미 받으신 수술의 결과는요?" |
| `A5` | 정보 없음을 없음으로 해석 | "다른 약은 없으시죠?" |

## C. 커버리지 부족

| 코드 | 이름 | 판정 | 가상 예시 |
|---|---|---|---|
| `C1` | 허위 연결 | coverage=NONE | 췌장염 질문에 뇌졸중 기준이 연결됨 |
| `C2` | 일부 조건만 확인 | coverage=PARTIAL | "A 또는 B" 중 A만 물음 |
| `C3` | 기록 보유 여부만 확인 | coverage=PARTIAL | "결과지가 있나요?"로 끝나고 제공 요청이나 항목 지정이 없음 |

## G. 묶기 오류

| 코드 | 이름 | 가상 예시 |
|---|---|---|
| `G1` | 서로 다른 사실 결합 | "신장에 문제가 있거나 약 용량을 바꾼 적이 있나요?" |
| `G2` | 서로 다른 기간 혼합 | 3개월 조건과 12개월 조건을 "최근에"로 합침 |
| `G3` | 서로 다른 대상 혼합 | 본인 병력과 가족력을 한 질문으로 합침 |
| `G4` | 서로 다른 측정값 혼합 | 두통 날 수와 발작 횟수를 한 숫자로 물음 |
| `G5` | 묶는 과정의 기준별 세부 조건 손실 | 공통 약물 질문으로 합치며 한 기준의 용량 조건이 빠짐 (PARTIAL) |

## T. 주제

| 코드 | 이름 | 설명 |
|---|---|---|
| `T1` | 주제 단일성 위반 | 독립된 사실을 한 번호에 넣음. 같은 사실의 직접 후속 정보(검사 여부 + 결과지)는 위반이 아니다. |

## R. 불필요한 중복

| 코드 | 이름 | 설명 |
|---|---|---|
| `R1` | 같은 세트 안의 동일 정보 반복 | `duplicate_of`에 앞 질문 번호를 적는다. 다른 기준의 다른 조건을 확인하는 반복은 해당하지 않는다. |
| `R2` | 입력에 이미 있는 정보 재질문 | 짧은 환자 설명에 명시된 내용을 다시 물음 |

## 기타 (`other_error`)

점수에 넣지 않고 기록만 한다.

| 코드 | 이름 | 설명 |
|---|---|---|
| `U1` | 환자 기억으로 수치 요구 | "크레아티닌 수치가 얼마인가요?" |
| `P1` | 적격 여부 고지·유도 | "이 시험에 적합하시려면 없어야 합니다." |

## S. 시뮬레이터 응답 (별도 감사)

질문 채점과 분리된 시트로, 채점 잠금 후 수행한다. 질문 품질의 오류가 아니다.

| 코드 | 이름 | 기준 |
|---|---|---|
| `S0` | 정상 | 질문 범위에 맞게 답함. 사실 자료에 없어 모른다고 한 경우 포함. |
| `S1` | 묻지 않은 정보 제공 | 질문이 요구하지 않은 사실까지 답함. 예: 결과지 보유를 물었는데 수치를 답함. |
| `S2` | 허구 정보 | 사실 자료에 없는 내용을 답함 |
| `S3` | 있는 정보 누락 | 사실 자료에 있는데 모른다고 답함 |
| `S4` | 복합 질문 일부 응답 | 질문의 일부에만 답함 |
