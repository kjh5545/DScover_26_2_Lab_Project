# 파일럿 비용 추정

실제 API를 호출하지 않고 계산하였다. **호출별 토큰을 측정한 기록이 저장소에 없으므로 모든 금액은 추정이다.** 재현 명령: `run_pilot.py estimate`

## 가격과 모델 확인 상태

| 항목 | 값 | 상태 |
|---|---|---|
| 모델 ID | `claude-sonnet-5-5` | 코드(`src/llm.py`)와 API 참조 자료 일치. API 호출로 사용 가능 여부는 **미확인** (키 없음). |
| 입력 가격 | $2 / 100만 토큰 | 코드와 API 참조 자료(2026-10-06 캐시) 일치. 오늘자 공식 가격은 **미확인**. |
| 출력 가격 | $10 / 100만 토큰 | 위와 같음. adaptive thinking 토큰은 출력으로 청구된다. |
| 프롬프트 캐시 | 사용하지 않음 | 파이프라인과 같은 요청을 유지하기 위함 |
| 배치 할인 | 사용하지 않음 | 호출별 토큰 기록과 단계 간 게이트를 유지하기 위함 |

## 단계별 추정

호출 1회 비용은 범위로 잡았다. 실행 수는 실제 코드에서 확인하였다.

| 단계 | 호출 수 | 호출당 비용 | 금액 |
|---|---|---|---|
| 질문 생성 (5조건) | 30 | $0.04~0.09 | $1.20~2.70 |
| 시뮬레이터 (4조건) | 24 | $0.003~0.01 | $0.07~0.24 |
| `reassess` (4조건) | 24~48 | $0.01~0.025 | $0.24~1.20 |
| `final_check` (4조건) | 48 | $0.015~0.03 | $0.72~1.44 |
| **소계** | **126~150** | | **$2.23~5.58** |
| 형식 실패 재시도 (10% 가정) | 최대 13~15 | | $0.22~0.56 |
| **총계** | | | **약 $2.5~6.1** |

- 핵심 조건 후속 실행(시뮬레이터 + 재판정 + 전체 재판정)은 96~120회, 약 $1.03~2.88이다.
- `reassess`는 질문이 다루는 시험 수에 따라 실행당 1~2회이다.
- A2s는 질문 생성 6회($0.24~0.54)뿐이다.
- 재시도 10%는 설계상의 여유이다. 기존 실행 기록에서 JSON 실패가 보고된 사례를 찾지 못했으므로 실제로는 더 낮을 수 있다. 다만 C0는 관측 기록이 없다.

## 호출당 비용의 근거

| 값 | 근거 |
|---|---|
| 질문 하한 $0.04 | 코드 주석: `review`를 빼면 비용이 약 절반. 전문 호출 약 $0.08의 절반 |
| 질문 상한 $0.09 | 10/22 비교 실행: 질문 4회에 약 $0.325, 회당 약 $0.08. 여유를 더함 |
| 시뮬레이터·재판정 | 10/22 루프: 24회 $0.591. 평가 세트 v3 배치 15회 $0.13(정가 환산 회당 약 $0.017). 답변이 추가되는 점을 반영 |

C0는 프롬프트가 794자로 짧아 입력 비용이 낮지만, 출력 길이는 관측되지 않았다.

## 기존 $3~5.5 추정과의 차이

| 항목 | 기존 (STEP 2) | 현재 |
|---|---|---|
| 총계 | 약 $3~5.5 | 약 $2.5~6.1 |
| 질문 | $1.2~2.4 | $1.2~2.7 |
| 후속 | 전 단계 호출당 $0.02 고정, $1.9~2.4 | 단계별 단가 적용, $1.03~2.88 |

**원인:** 금액의 중심은 크게 바뀌지 않았다. 범위가 넓어진 것은 후속 호출의 단일 평균을 단계별 범위로 나눴기 때문이다. 시뮬레이터 호출이 판정 호출보다 훨씬 작아 하한이 내려갔고, 답변이 포함된 전체 재판정을 더 크게 잡아 상한이 올라갔다. 질문 상한은 기존 기록의 $0.08에 여유를 더해 올렸다.

## 측정 계획

유료 질문 생성이 끝나면 호출별 토큰과 비용이 `attempts/`와 `questions/*.json`에 남는다. 질문 단계의 실제 비용을 확인한 뒤 후속 단계 실행 여부를 판단한다.
