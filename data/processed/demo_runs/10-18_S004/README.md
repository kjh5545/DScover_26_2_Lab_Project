# 데모 리허설 · S004 (10/18, 주희)

`streamlit run app.py`에서 S004(68세 남성, 방광암 의심, 짧은 설명)로 분석한 뒤, 1라운드 질문 5개에 답했어요. CSV는 화면의 시험별 판정표를 내려받은 거예요.
- 답을 제출한 뒤에 저장했고, "질문 끝내기(전체 재판정)"는 누르지 않았어요.
- 이때는 질문을 한꺼번에 보여 주는 화면이었어요. 엔터로 제출됐고, 두 번 제출됐을 수 있어요. 그래서 화살표(이전 → 이후)는 마지막 제출에서 바뀐 것만 남았어요.
- 이후 질문을 하나씩 보여 주게 바꿨어요(362ae29).

## 질문과 답 (답은 인선 상세 설명에 맞춰 작성)
| 질문 | 답 |
|---|---|
| Q1 방광 종양 조직검사를 받은 적이 있나요? | 아직 조직검사 결과는 없어요. 이틀 전 방광내시경에서 종양이 보였고, 조직검사는 다음주 수술때 하기로 했어요. |
| Q2 방광 수술, 항암 약물치료, 방사선치료를 받은 적이 있나요? | 아니요, 방광 수술이나 항암치료, 방사선치료를 받은 적은 없어요. |
| Q3 최근 5년 안에 암으로 진단받거나 치료받은 적이 있나요? | 아니요, 암 진단을 받은 적은 이번이 처음이에요. |
| Q4 경요도 방광종양 절제술이나 방광절제술 날짜가 잡혀 있나요? | 방광 종양을 내시경으로 제거하는 수술이 다음주로 예정되어 있어요. 방광 전체를 떼는 수술은 잘 모르겠어요. |
| Q5 영상검사에서 방광 밖으로 퍼졌다는 설명을 들은 적이 있나요? | 가슴, 배, 골반 CT에서 림프절이 커지거나 다른 곳으로 퍼진 소견은 없다고 들었어요. |

Q2·Q3은 상세 설명에 없는 내용이라, 68세에 처음 진단받은 환자로 가정해서 "없음"으로 답했어요. 답은 CSV 근거에 인용된 문장을 그대로 옮겼어요. 근거 칸이 120자에서 잘려서, 실제 답은 더 길었을 수 있어요.
